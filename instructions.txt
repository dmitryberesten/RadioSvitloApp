### Опис завдання для GitHub Copilot

Створити додаток на React Native з використанням Expo, який відображатиме веб-сайт у компоненті WebView. Завантажити сайт за посиланням: [http://www.radio-svitlo.com](http://www.radio-svitlo.com)

-----

### Покрокова інструкція для виконання завдання:

1.  **Створення проекту Expo**: Відкрийте термінал у VS Code та виконайте команду:
    ```bash
    expo init RadioSvitloApp
    ```
2.  **Перехід у папку проекту**:
    ```bash
    cd RadioSvitloApp
    ```
3.  **Встановлення бібліотеки WebView**: Використовуйте `expo install`, щоб уникнути проблем із сумісністю:
    ```bash
    expo install react-native-webview
    ```
4.  **Відкриття файлу `App.js`**:
    Відкрийте файл `App.js` у вашому редакторі.
5.  **Вставка промпта для Copilot**: Вставте наступний текст на початку файлу. Copilot прочитає його та згенерує необхідний код.

-----

### Промпт для GitHub Copilot

```javascript
/**
 * Створити новий функціональний компонент на React Native для додатка Expo.
 * Компонент повинен відображати веб-сайт у компоненті WebView.
 * Посилання на сайт, який потрібно завантажити: "http://www.radio-svitlo.com".
 *
 * Увага до деталей:
 * 1. Імпортувати необхідні бібліотеки: React, StyleSheet, View.
 * 2. Імпортувати WebView з 'react-native-webview'.
 * 3. Назвати компонент "App".
 * 4. Загорнути WebView у компонент <View> з властивістю flex: 1, щоб заповнити весь екран.
 * 5. Для WebView встановити властивість source з посиланням на ваш сайт.
 * 6. Створити об'єкт StyleSheet для стилізації компонентів.
 * 7. Експортувати компонент App за замовчуванням.
 */
```
